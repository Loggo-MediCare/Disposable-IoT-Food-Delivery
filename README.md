# Disposable-IoT-Food-Delivery

用完即丟的低成本 IoT 食品配送裝置 — 產品研發技術紀錄。

## 核心原則

1. **最高目標：** 用完即丟，便宜到丟掉也不心疼。
2. **最高約束：** 食品安全，封條破損絕對不能食用。
3. **設計策略：** 透過中央運算、低成本硬體與軟體容錯，降低單次配送成本。

## 討論主題

- AAA 電池
- 馬達與 H-bridge 成本
- BLE / Wi-Fi 部署
- ESP32
- NVIDIA Newton
- 輪足機構
- UDP 容錯
- 防拆封條
